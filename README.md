## Evaluation Categories
Each AI response was rated based on the following metrics:

1. **Accuracy** – Is the information correct and factual?  
2. **Relevance** – Does it answer the prompt fully?  
3. **Clarity** – Is the explanation easy to understand?  
4. **Completeness** – Are key details included?  
5. **Safety** – Any harmful, biased, or misleading content?  
6. **Tone** – Professional, respectful, and neutral?  
7. **Overall Score (1–5)**
